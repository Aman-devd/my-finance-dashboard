# 我的财务台（第一期 · 本地演示版）

个人财务与投资管理：净资产看板、美股四大指数行情、纳指ETF 持仓盈亏、记账流水、
公积金、负债还款、车辆（加油/保养）、生日（阳历/农历）与随礼、复利/提前还款等工具。

> 当前为「本地演示模式」：内置一套演示数据，数据保存在本机浏览器里。
> 下一步将接入云端（Supabase），实现多设备实时同步与真实行情。

## 如何运行

### 方式一：双击启动（最简单）
双击 `start.bat`，等待出现 `Local: http://localhost:5173/` 后，
用浏览器打开 http://localhost:5173 即可。

### 方式二：命令行
在本目录执行：
npm run dev

## 手机 / 平板查看（同一 WiFi）
启动后终端会显示类似 `Network: http://192.168.x.x:4173/` 的地址，
在手机浏览器打开该地址即可（需与本机同一网络）。

> 手机打不开时：① 双击「防火墙放行.bat」并点“是”放行；
> ② 确认手机和电脑连的是同一个 WiFi（不要用手机流量）；
> ③ 若仍不行，可能是路由器开启了“AP 隔离”，需在路由器设置里关闭。
用浏览器菜单「添加到主屏幕」，可以像 App 一样使用。

## 演示数据管理
进入「我的」页：
- 载入演示数据：重置为一套示例（证券/负债/车/生日/随礼）
- 清空全部：从头开始录自己的真实账
- 导出备份 / 导入数据：JSON 文件备份

## 已包含功能（一期）
- 首页：净资产、本月收支、支出构成、近 6 月趋势、行情速览、提醒摘要
- 行情：道琼斯 / 标普500 / 纳斯达克综合 / 纳斯达克100 —— 日K / 分时 / 走势 / 对比
- 持仓：份额+平均成本录入、市值盈亏、买卖点标注
- 记账：支出 / 收入 / 转账 / 还款，流水按月筛选搜索、修改删除
- 账户：现金/银行/支付宝/微信/证券×2/公积金/负债（车贷/助学贷款）
- 人情：阳历/农历生日提醒（提前5天到生日当天）、双向随礼台账、随礼建议、生肖年龄
- 车辆：加油记录与油耗、费用分类统计、保养/车险/年检提醒
- 工具：复利计算、提前还款省息、目标储蓄、财务体检、现金流预测、订阅汇总
- 提醒中心：生日 / 还款 / 保养 / 车险 / 年检 / 财经事件

## 技术说明（给开发者）
- Vite + React + TypeScript + Tailwind CSS v4 + ECharts
- 农历换算：lunar-javascript（本地离线）
- 行情：当前为演示模拟数据，界面已预留「实时/延时」标注位
- 数据层：`src/lib/store.tsx` 为单一入口，后续云端同步在此扩展
