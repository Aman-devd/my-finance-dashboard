> 生成日期：2026-09-09　|　面向对象：接手继续开发的 AI / 开发者　|　配套：同目录「源码/」+「数据库/」

## 一、这是什么
一款**单人多设备**的个人财务管理 Web 应用：仪表盘（净资产/收支/投资）、美股四大指数与国内纳指ETF(513100)行情、持仓盈亏、流水记账、账户/负债/借贷、亲友生日与随礼、纪念日、车辆(加油/保养/保险)、提醒(个人+理财)、农历、日历、复利等工具、密码保险箱(本地加密)、年度总结、云端多设备同步与历史恢复。中文界面，手机/平板/电脑自适应。

## 二、给接手 AI 的铁律（先读这个）
1. **绝不外泄/不写入代码库**：数据库密码(service_role key / 数据库连接密码)只属于用户本人，任何 AI 都不要索要、不要粘贴、不要写进 .env 或文档。`源码/.env` 里只有公开的 Supabase 项目地址和 anon(publishable) key，这是安全且正常的。
2. **改数据库结构**：必须在用户的 Supabase 控制台(SQL Editor)由用户亲自执行 SQL，AI 无法也不应执行 DDL。文档提到的“待执行 SQL”要明确交给用户。
3. **安装与构建**：`npm install` → `npm run dev`(开发) / `npm run build`(产物在 dist)。不要改动 node_modules/dist。
4. **不要上传统一提交 .env 与密钥**；保持 `.env.example` 有占位说明。
5. **手机访问**：预览服务 `npm run preview -- --host --port 4174` 已开在局域网；Windows 防火墙需先运行 `防火墙放行.bat`(管理员)。手机用的是电脑局域网 IP(会变，用 `ipconfig` 查)，不是 localhost。

## 七、数据同步与“绝不丢数据”设计（核心，改这里要极小心）
整体是“整份 JSON 文档同步”，单人够用。已实现防丢机制，位于 `src/lib/store.tsx`：
1. **单线程串行保存**：同一时刻只有一个上传在途；每次上传前取最新数据，杜绝“旧上传晚到盖掉新结果”。
2. **合并保险(merge-on-save)**：保存前若发现云端有本机没见过的更新(基于 baseSig 基线比较)，自动把两边按记录 id 取并集合并后再上传——两台设备同时改也不互相覆盖。
3. **脏标记**：有改动没上传成功就记 `finance.app.dirty.v1`，下次打开优先推本机，绝不因拉旧云端而丢改动。
4. **回前台/联网自动拉最新**；`pagehide/visibilitychange` 时补发一次(防移动端杀进程)。
5. **危险操作自动备份**：清空/载入演示/导入前自动存本机历史(`finance.app.history.v1`，12 份)，「我的」页可一键恢复。
6. **保存反馈**：顶部状态条 同步中/已保存/网络错误；失败自动重试。
7. **自动更新**：构建时生成 `dist/version.json`(时间戳，经 vite define `__BUILD_TS__` 注入)，页面回到前台发现版本不一致会自动刷新升级，避免“旧页面互相覆盖”。

## 八、真实行情接入说明（`src/lib/quotes.ts` + `market.ts`）
- 报价：腾讯财经 `https://qt.gtimg.cn/q=usNDX,usIXIC,usINX,usDJI,sh513100`，字段按 `~` 分割(见 parse)，每 15 秒刷新，页面不可见时暂停。
- 日K：`web.ifzq.gtimg.cn` 的 usfqkline(美股)/fqkline(A股) 接口，约 430 个交易日缓存，30 分钟重取。
- 分时：全部 5 个标的（4 美股指数 + A股513100）均用腾讯财经 `minute/query` 接口，交易时段真实 1 分钟粒度，60 秒刷新；非交易时段仅返回收盘价，此时自动回退演示分时曲线（见 market.ts intradaySeries）。
- 代码映射：NDX→usNDX、IXIC→usIXIC、SPX→usINX、DJI→usDJI、513100→sh513100；`quoteOf/klineSeries/intradaySeries` 都是“真实缓存优先，否则回退演示”，保证离线不白屏。
- 已知限制：溢价率/成交量/IOV 仍为估算；美股非交易时段分时为演示曲线（交易时段自动切换为真实数据）。
- 刷新驱动：`useLiveQuotes()` 返回计数触发组件重渲染（Market/Dashboard 已接）。

## 九、设计语言约定（重要，避免“倒退”）
已确定方向：**极简编辑型**——单一主色相(品牌蓝/深海军蓝)只作强调锚点，涨跌用红/绿(语义色，勿改：国内习惯红涨绿跌)，其余装饰色收敛为中性灰；靠字号/字重分层；卡片细线扁平；数字用表格数字(tabular-nums)。
- 避免：文字箭头(→/›)与 emoji 作按钮装饰(已清理)；渐变紫/玻璃拟态堆砌；大圆角+厚投影的“消费感”。
- 曾尝试并被用户否决/回退的：taste-skill 整套营销页化改版、HeroUI/Tremor 整库换肤；用户认可的是 Tremor 中性底+深海军蓝大卡这一路线上的“极简编辑型”精修。手机端要单独检查(导航对称、底部安全区、字号16px防缩放)。
- 回退快照目录：`版本快照/`（与源码目录平级，在父目录），需要时可覆盖恢复。
